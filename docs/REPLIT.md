# Replit handoff

## Run this version

Import the Git repository or upload the project directory into a Node.js project. Run `npm start`; `.replit` supplies the same command and port mapping. If Replit offers automatic framework generation, preserve the supplied project files. This version needs no dependency installation and no API keys.
